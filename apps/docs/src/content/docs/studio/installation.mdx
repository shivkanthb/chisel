## Installation

<CodeTabs
  npm="npm i chisel-studio"
  pnpm="pnpm add chisel-studio"
  bun="bun add chisel-studio"
/>

### Peer dependencies

`chisel-engine` is a peer dependency — install it alongside Studio:

<CodeTabs
  npm="npm i chisel-engine"
  pnpm="pnpm add chisel-engine"
  bun="bun add chisel-engine"
/>

`hono` is included as a direct dependency and will be installed automatically.

`chisel-studio` embeds its own UI bundle and starts a Hono server around your existing engine instance. It does not create or start the engine for you.
